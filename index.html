§ 04 - Flagship Build

Built solo. Runs itself.

My personal R&D - and a working manifesto for how I build: AI-native, agent-first, and autonomous by default. One engineer, one repo, a system that researches markets and improves on its own.

A

AI-Native

Built end-to-end with Claude Code CLI - agents, hooks, skills and CLAUDE.md context. The repository itself is the proof of concept.

B

Agent-First

Every pipeline stage is its own autonomous worker. The system discovers, scores and plans with no human in the loop.

C

Self-Improving

A rediscovery loop re-mines opportunities from previous cycles - the engine gets sharper every run, by itself.

Solo Build · 2025 - Present

Autonomous AI Growth Engine

SEO SaaS Platform

An autonomous SEO platform that runs keyword research, competitor analysis and content planning on its own - no manual input. Each BullMQ worker owns a stage of the pipeline, so the system discovers, scores and re-discovers opportunities in a self-improving loop.

  • Agent-per-stage - a multi-agent BullMQ pipeline: competitor discovery, keyword scoring, content-gap analysis - each stage autonomous.
  • Self-improving - a rediscovery pipeline that mines new keyword opportunities from previous analysis cycles.
  • Real signals - OpenAI for niche detection, DataForSEO for market data, Google Search Console for ranking signals.
  • AI-native end-to-end - built entirely with Claude Code CLI (agents, hooks, skills, CLAUDE.md). Plain JS + raw SQL via pg-promise for fast AI-assisted iteration.
